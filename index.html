🧶 VoxelWeave Studio

用调色板织出确定性、可无缝平铺的低多边形贴图，并导出 PNG 图集与 JSON 清单。全程离线运行，数据不离开浏览器。

织格参数

最终图集尺寸 = 列数 × 单元格尺寸（宽）、行数 × 单元格尺寸（高）。
相同种子与参数必然生成完全一致的织格；更换种子会改变颜色分布。
支持 #rgb、#rrggbb、#rrggbbaa、 rgb() 与 rgba()。每种颜色至少出现一次； 颜色多于格子时按顺序取前若干个。

画布预览

调整参数后点击“重新织格”，再点击“导出”下载 PNG 图集与 JSON 清单。
