# 把效果交给 AI 接入

[English](ai-integration.md) · [仓库首页](../README.zh-CN.md) · [效果目录](../effects/README.zh-CN.md)

## 选好需要交给 AI 的文件

在[效果目录](../effects/README.zh-CN.md)找到效果，将对应文件夹完整复制进你的项目，包括 JavaScript、CSS、演示文件和附带的依赖、许可证。也可以直接把仓库和效果文件夹的路径交给 AI。

需要让 AI 在仓库里找效果时，可以先读 [catalog.json](../catalog.json)。索引包含中英文名称与介绍、分类、在线预览地址、文件夹位置、准确的挂载函数名和文件依赖。选定效果后再读对应源码，通常不需要一次读取全部效果。

分类列表的第一项是主分类，其余是辅助检索标签。一个效果可以属于多个分类，文件夹路径统一为 `effects/<slug>/`。

## 告诉 AI 放在哪个页面、想改什么

```text
把 effects/orbit-cursor/ 接入这个项目的页头。

先读 effect.js 开头的说明，以及 index.html 中的挂载调用。
适配项目现有的布局和颜色，保留原有的动效行为。
加载需要的 CSS 和脚本，在页面或组件卸载时清理实例。
保留版权注释和附带的许可证。

说明对交互做了哪些调整，并检查桌面和手机宽度下的效果。
```

同时提供目标页面或组件、项目使用的框架，以及希望替换的文字、图片、颜色。具体选项、DOM 要求和公开 API，以该效果源码开头的说明为准。

## 接入前先看示例

效果文件夹里的 `index.html` 展示了脚本加载顺序、所需结构和挂载参数。环绕光标的基础接法是：

```html
<link rel="stylesheet" href="./effects/orbit-cursor/effect.css">
<div id="orbit" style="height: 240px"></div>
<script src="./effects/orbit-cursor/effect.js"></script>
<script>
  const fx = mountOrbitCursor(document.getElementById('orbit'));
</script>
```

不同效果的接入要求有差别：

- 有些效果需要空容器，有些效果增强已有内容。例如逐词阅读点亮接收现有文章节点，边缘折射色散接收视口及其现有内容子节点。
- 按说明给容器设置稳定尺寸。有些效果要求明确高度，旋转标签手风琴则按内容测量高度。
- 弧面画廊、圆盘轮播和长按迸发需要先加载附带的 `three.min.js`，再加载 `effect.js`。
- 示例文字、图片和页面排版可能位于 `index.html`。只复制 `effect.js` 不会自动带上这些示例内容。

## 接入 React、Vue 等现有项目

等容器挂到浏览器 DOM 后再创建实例。保存返回的实例，并在组件或页面卸载时调用文档中对应的清理方法。框架在开发模式下重复挂载时，也需要在两次挂载之间完成清理。

按效果约定划分 DOM 的控制范围。效果运行期间，避免框架同时重建它正在操作的节点。增强现有内容的效果与自行创建内容的效果，节点归属规则可能不同。

有公开的参数或内容更新方法时，优先通过这些方法更新实例。具体方法名以源码说明为准，例如不同效果可能使用 `setReducedMotion` 或 `setReduced`，不要假设所有效果都有完全一致的 API。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 没有显示效果 | 容器尺寸、所需结构、CSS 是否加载、脚本顺序。 |
| 找不到挂载函数 | `catalog.json` 里的入口名，以及示例中的脚本标签。 |
| 画廊没有图片 | 示例从哪里提供图片内容，相关资源是否一并复制。 |
| 切换页面后表现异常 | 卸载清理、重复挂载，以及生成节点是否被框架重建。 |
| 动画减弱或不播放 | 效果说明中的减少动态效果行为，以及设备上的对应设置。 |

独立示例不需要构建。如果目标应用或部署环境有不同的资源加载规则，在应用中调整路径。复制代码时保留版权注释和 [Effect Atlas 许可协议](../LICENSE)。
